## Основні можливості (MVP)
- Додавання завдання: назва 1–100 символів, предмет ≤ 60, дедлайн (дд.мм.рррр), позначка «Прострочено».
- Позначення виконаним, видалення з підтвердженням.
- Збереження в localStorage зі схемою, копією пошкоджених даних і банером помилок.
- Коректна робота у кількох вкладках; правильна форма лічильника.

## Запуск
Сервер, збирання й змінні середовища не потрібні: відкрийте `src/index.html`. Для тестів — Node.js ≥ 18, `npm test`. Міграцій немає; ключ сховища `studyplanner.tasks.v1` не змінювався.

## Відомі обмеження
1. Дані лише в браузері; немає синхронізації між пристроями. Вплив: на іншому пристрої список порожній. Обхідного шляху немає (поза MVP).
2. Облікових записів і ролей немає → перевірка прав доступу (TC-23) не застосовна; дані бачить власник браузерного профілю.
3. Якщо один запис пошкоджений, увесь список вважається пошкодженим (копія в `…v1.backup`).
4. Firefox і Safari не перевірялись (TC-22, Blocked): у середовищі виконання був лише Chromium.
5. Тестувала й розробляла одна особа; незалежного (перехресного) тестування не було.
6. Відкрита сторінка не оновлює «Прострочено» після опівночі до наступної дії/перезавантаження.
7. DEF-06: у README ще немає посилання на GitHub Project — додати до подання.
