# StudyPlanner

StudyPlanner — навчальний вебзастосунок для планування завдань і дедлайнів студентів.

## Проблема
Навчальні завдання надходять із різних джерел, тому студенту складно зібрати їх в одному місці та контролювати строки.

## Мета MVP
Дати змогу створити завдання, вказати предмет і дедлайн, переглянути список та позначити завдання виконаним.

## Функції
- Додавання завдання.
- Назва, предмет і дедлайн.
- Позначення виконаного завдання.
- Видалення завдання.
- Локальне збереження у браузері.

## Запуск
Відкрийте `src/index.html` у сучасному браузері. Сервер або встановлення залежностей не потрібні.

## Структура
- `src/` — інтерфейс застосунку.
- `docs/` — документація проєкту.

## Статус
Навчальний MVP. Дані зберігаються локально в браузері й не синхронізуються між пристроями.

## Авторство
Індивідуальний навчальний проєкт. Виконавиця: Ніка Семенових, група 4ІПЗ 23.
