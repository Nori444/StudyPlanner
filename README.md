# StudyPlanner

## Опис проєкту
StudyPlanner — це навчальний вебзастосунок для планування завдань і контролю дедлайнів студентів.

## Проблема
Студентам складно контролювати навчальні завдання, які надходять із різних джерел. Через це можна забути про важливі дедлайни.

## Мета проєкту
Створити зручний застосунок, який допомагає організовувати навчальні завдання в одному місці.

## Основні можливості
- Додавання навчальних завдань.
- Вказування навчального предмета.
- Встановлення дедлайнів.
- Перегляд списку завдань.
- Позначення виконаних завдань.
- Видалення та редагування завдань.

## Цільова аудиторія
Студенти, які хочуть краще організувати свій навчальний процес.

## MVP
Перша версія застосунку включає основні функції створення, перегляду та контролю навчальних завдань.

## Технології
HTML, CSS, JavaScript, GitHub.

## Статус
Навчальний MVP. Дані зберігаються локально в браузері й не синхронізуються між пристроями.

## Авторство
Індивідуальний навчальний проєкт. Виконавиця: Ніка Семенових, група 4ІПЗ 23.
