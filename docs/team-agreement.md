# Угода про роботу (індивідуальний формат)

Проєкт виконується однією студенткою, тому командні ролі суміщені.

## Правила
- Планувати роботу невеликими задачами.
- Одночасно тримати не більше 1–2 активних задач.
- Фіксувати зміни зрозумілими commit-повідомленнями.
- Перевіряти функцію перед позначенням задачі виконаною.
- Не додавати паролі, токени чи персональні дані до Git.
- Оновлювати README та документацію після суттєвих змін.

## Definition of Done
Задача завершена, якщо функція працює, основний сценарій перевірений, критичних помилок немає, а документація актуальна.
