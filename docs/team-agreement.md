# Угода про роботу (індивідуальний формат)

Проєкт виконується однією студенткою, тому командні ролі суміщені; роль зовнішнього рецензента виконує одногрупник або викладач.

## Правила
- Планувати роботу задачами до 2–4 год.
- WIP: In Progress ≤ 1, Review/Test ≤ 2 (оновлено 19.11.2026; раніше було 1–2).
- Фіксувати зміни зрозумілими commit-повідомленнями з номером задачі (наприклад, «T5: підтвердження видалення»).
- Перевіряти функцію перед позначенням задачі виконаною.
- Не додавати паролі, токени чи персональні дані до Git.
- Оновлювати README та документацію після суттєвих змін.

## Definition of Ready
1. Задача пов’язана з SP-xx. 2. Є критерій завершення й тест-кейс. 3. Відомі вхідні дані. 4. Попередник завершений. 5. Оцінка ≤ 2 год. 6. Є місце у WIP.

## Definition of Done
1. Критерії завершення виконано. 2. Код у репозиторії, без секретів. 3. Немає помилок у консолі. 4. Тест-кейс пройдено й записано. 5. Помилки введення оброблено. 6. Review або самоперегляд із перервою ≥ 12 год. 7. Backlog, дошку й README оновлено.
