## Додатково (поза демо, для відповідей на запитання)
- SP-12, правильна форма лічильника — TC-18, DEF-04 (Pass).
- Безпека: XSS через `textContent` — TC-13; секрети — TC-21 (`scripts/check-secrets.sh`).
- Не застосовно: TC-23 (ролі) і TC-24 (API) — облікових записів і сервера немає (charter).
- Обмеження перевірки: TC-22 Firefox/Safari — Blocked.

## Прогалини, виявлені матрицею
1. NFR-01 не має виміряного доказу → замір на репетиції.
2. Реалізації без вимоги немає, а вимога без перевірки одна — NFR-01. Усі SP-04…SP-13 мають тест, кожний крок демо D2–D7 посилається на ID вимоги.
