# ADR-001: Вибір технологічного стека

- **Статус:** прийнято, 19.11.2026
- **Контекст:** індивідуальний навчальний проєкт; MVP — одна сторінка з формою та списком; NFR-01 (швидкий сценарій) і NFR-03 (без сервера й реєстрації); обмежений час; стартовий код уже на HTML/CSS/JavaScript.
- **Рішення:** HTML5, CSS3, JavaScript (ES2020) без фреймворків і збирання; хостинг — GitHub Pages; Git/GitHub. Логіка розділена на модулі Task Service, Storage Adapter, Message Center.
- **Альтернативи:** React/Vue SPA (надлишково для однієї сторінки); backend FastAPI/Node (суперечить NFR-03); low-code (слабкий контроль коду).
- **Наслідки:** (+) нуль залежностей, миттєве розгортання, простота ручного тестування; (–) ручна підтримка структури й оновлення DOM; за зростання інтерфейсу — розглянути фреймворк.
- **Умови перегляду:** з’являються акаунти, спільні плани або кілька складних екранів — новий ADR.
