## 3. Дослідницька сесія (≈15 хв, ризик «дані й введення»)
Маршрут: емодзі в назві → 5-значний рік → довгі слова на 375 px → ручне редагування localStorage → дві вкладки → подвійний клік → Enter. Знайдено DEF-01…05. Спостереження без дефекту: подвійний клік «Додати» створює одне завдання, але другий клік показує «Введіть назву завдання» на порожній формі — поведінка узгоджена з правилом валідації, не дефект.
