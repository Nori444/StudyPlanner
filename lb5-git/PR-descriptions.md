# Тексти pull request

Номери issues (#1…) відповідають порядку створення карток скриптом `scripts/create-issues.sh` (T1…T15). Якщо номери інші — виправте.

Порядок: PR зливається в `main`, потім `git switch main && git pull`, потім наступний `apply.sh`.
