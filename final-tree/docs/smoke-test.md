# Smoke test після злиття в main

Виконується в чистому профілі браузера (або після `localStorage.clear()` у консолі). Час — близько 5 хвилин.

| № | Крок | Очікуваний результат |
|---|---|---|
| 1 | Клонувати репозиторій у новий каталог, відкрити `src/index.html` | Сторінка відкривається, у консолі немає помилок, видно «Поки що завдань немає» |
| 2 | Додати «Лабораторна робота №5», предмет «Проєктний практикум», дедлайн у майбутньому | Завдання у списку; дедлайн у форматі дд.мм.рррр |
| 3 | Додати завдання з учорашнім дедлайном | Біля дедлайну позначка «Прострочено» |
| 4 | Відмітити завдання виконаним | Назва закреслена; «Прострочено» зникає |
| 5 | Оновити сторінку (F5) | Усі завдання й стани збережені |
| 6 | Спробувати додати порожню назву або лише пробіли | Повідомлення під полем, завдання не додано |
| 7 | Спробувати додати назву з 101 символа | Повідомлення про правило «від 1 до 100», завдання не додано |
| 8 | «Видалити» → «Скасувати», потім «Видалити» → підтвердити | Після скасування запис лишається; після підтвердження зникає |
| 9 | У консолі: `localStorage.setItem("studyplanner.tasks.v1","{не json")`, оновити сторінку | Порожній список, банер про пошкоджені дані; копія в `studyplanner.tasks.v1.backup` |
| 10 | Автоматично: `npm test` | Усі unit-тести проходять |

Підсумок записують у PR або в звіт: дата, коміт `main`, браузер, результат кожного кроку.
